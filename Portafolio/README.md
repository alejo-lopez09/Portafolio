# Portafolio de Alejandro López

Portafolio de desarrollador junior: sobre mí, proyectos (qué hace cada uno y qué aprendí) y habilidades.

Demo: https://alejandro-portafolio-three.vercel.app/

## Estructura
- `index.html`: estructura y contenido fijo (hero, sobre mí, contacto).
- `script.js`: datos de proyectos y habilidades. Edita aquí para agregar o cambiar proyectos.
- `style.css`: estilos.

## Cómo agregar un proyecto
Añade un objeto al arreglo `projects` en `script.js` con `name`, `tags`, `alcance`, `aprendizaje` y `repo`.
