# Portafolio de Alejandro López

Portafolio de desarrollador junior: identidad profesional, formación, proyectos (qué resuelve cada uno, mi participación, retos y aprendizajes) y habilidades técnicas.

Demo: https://alejandro-portafolio-three.vercel.app/

## Estructura
- `index.html`: estructura y contenido fijo (hero, sobre mí, contacto).
- `script.js`: aquí editas todo: datos personales (correo, LinkedIn, CV, foto), formación, proyectos y habilidades. Lo que dejes vacío no se muestra.
- `style.css`: estilos.

## Cómo agregar un proyecto
Añade un objeto al arreglo `projects` en `script.js` con `name`, `tags`, `alcance`, `reto`, `aprendizaje` y `repo`. Opcionales: `problema`, `rol`, `demo` (enlace en vivo) e `img` (captura de pantalla).
